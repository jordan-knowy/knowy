====================================================
POSITIONNEMENT GLOBAL DU PRODUIT
================================

KNOWING n’est PAS :

* un assistant de réunion classique
* un outil de transcription
* un analyseur de personnalité
* un simple outil CRM

KNOWING est :
“Une plateforme d’intelligence relationnelle”.

La plateforme :

* prépare automatiquement les réunions
* comprend les personnes présentes
* cartographie les organisations
* analyse les dynamiques relationnelles
* assiste pendant les conversations
* construit une mémoire organisationnelle persistante
* synchronise les informations stratégiques dans les CRM

L’expérience doit être :

* élégante
* calme
* premium
* intelligente
* rassurante
* humaine
* ultra lisible
* enterprise-grade
* AI-native

IMPORTANT :
La plateforme ne doit JAMAIS donner une sensation :

* creepy
* Black Mirror
* surveillance
* manipulation psychologique
* cyberpunk
* froide ou militaire

La plateforme doit donner la sensation :
“d’un assistant stratégique élégant qui aide à mieux comprendre les relations humaines et les organisations.”
